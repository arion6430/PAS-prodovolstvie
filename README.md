# Прогнозно-аналитическая система цен на плодоовощную продукцию

Учебный проект по дисциплине «Прогнозно-аналитические системы», профиль «Управление данными».
Тема 8 — продовольственный рынок.

**Прогнозируемый показатель:** средняя потребительская цена (руб/кг) на плодоовощную продукцию в разрезе РФ, федеральных округов, Москвы и Санкт-Петербурга. Горизонт прогноза — 1–3 месяца.

**Пользователь:** аналитик закупок торговой сети или регионального органа, который следит за продовольственными ценами.

Постановка задачи и анализ источников: [docs/01_Постановка_задачи_и_данные.md](docs/01_Постановка_задачи_и_данные.md).

## Источники данных

| Источник | Способ получения | Частота |
|---|---|---|
| ЕМИСС 31448 — средние потребительские цены | HTML + POST-выгрузка SDMX-XML | месяц |
| ЕМИСС 57693 — средние цены производителей с/х продукции | HTML + POST-выгрузка SDMX-XML | месяц |
| Банк России — официальные курсы валют | XML API | день |
| Банк России — ключевая ставка | HTML-таблица | день |
| Open-Meteo — историческая погода | JSON REST API | день |

## Структура репозитория

```
config/      конфигурация и мастер-справочники (товары, регионы, соответствие кодов)
docs/        постановка задачи, архитектура, описание данных
research/    разовые исследовательские скрипты
```

Инструкция по запуску будет дополняться по мере реализации компонентов.
