# Аналитический модуль: витрины и дашборды

Дашборды предназначены для принятия решений: каждый элемент отвечает на конкретный вопрос пользователя и назван этим вопросом. Superset читает только витрины `marts.*` под ролью `bi_reader`, у которой есть права только на чтение. Витрины пересобирает dbt при каждом запуске DAG, поэтому дашборды обновляются автоматически.

Дашборды хранятся как код: [`superset/bootstrap.py`](../superset/bootstrap.py) идемпотентно создаёт подключение, датасеты (с русскими подписями колонок), графики и дашборды с фильтрами. Повторный запуск обновляет объекты, а не дублирует их.

## Предметный дашборд «Цены на плодоовощную продукцию»

Пользователь — аналитик закупок. Задача — вовремя заметить аномальный рост цен и спланировать закупки и запасы.

| Вопрос пользователя (название элемента) | Тип | Витрина | Какое решение поддерживает |
|---|---|---|---|
| Сколько стоит товар сейчас и как изменилась цена? | таблица, подсветка отклонения > 20 % и < −10 % | `mart_price_latest` | общая картина за последний опубликованный месяц |
| Какие товары сейчас дороже сезонной нормы? | горизонтальные столбцы | `mart_price_latest` | что закупать с осторожностью или искать замену |
| Как менялись цены? | линии по товарам | `mart_price_monthly` | долгосрочный тренд и сезонность |
| Цена против сезонной нормы: аномалия или обычная сезонность? | две линии: цена и норма | `mart_price_monthly` | отличить обычный весенний рост от аномального |
| Во сколько раз розничная цена выше цены производителя? | линии по товарам | `mart_price_monthly` | переговорная позиция с поставщиками, рост наценки в цепочке |
| В каких регионах цены сильнее всего выше нормы? | тепловая карта регион × товар | `mart_price_latest` | где закупать и откуда везти |
| Какие товары подорожают, если ослабнет рубль? | столбцы: корреляция с курсом сразу и через 3 месяца | `mart_fx_sensitivity` | какие позиции страховать при ослаблении рубля |

**Фильтры:** «Регион» (по умолчанию — РФ), «Товар» (несколько товаров для линейных графиков), «Товар для сравнения с нормой» (один товар, иначе среднее по разным товарам не имеет смысла), «Период». Фильтры применяются только к тем графикам, для которых они имеют смысл: например, тепловая карта показывает все регионы и фильтр региона не учитывает.

**Сезонная норма** — средняя цена того же календарного месяца за 5 предыдущих лет (не меньше 3 наблюдений). Отклонение от неё показывает аномалию, очищенную от обычной сезонности: весной картофель дорожает каждый год, и сам по себе этот рост сигналом не является.

## Операционный дашборд «Операционный мониторинг конвейера данных»

Пользователь — владелец системы. Задача — убедиться, что аналитикам показываются свежие и корректные данные, и быстро найти сбой.

| Вопрос | Тип | Витрина |
|---|---|---|
| Актуальны ли данные всех источников? | таблица: последние данные, отставание, допустимое отставание (SLA), последний успешный запуск, сбои за 7 дней, состояние | `ops_source_freshness` |
| Стабильно ли проходят загрузки? | столбцы по дням с разбивкой по статусам | `ops_load_log` |
| Сколько новых данных и ревизий приходит? | столбцы: новые и изменённые строки по дням | `ops_load_log` |
| Что произошло в последних запусках? | таблица 50 последних загрузок с ошибками и предупреждениями | `ops_load_log` |
| Есть ли проблемы качества данных и как система их обработала? | таблица контролей: затронуто строк, действие системы | `ops_data_quality` |

Допустимое отставание по каждому источнику задано в справочнике `dbt/seeds/source_sla.csv`: для месячных данных Росстата — 60–90 дней, для дневных — 5–7 дней.

## Происхождение показателя (пример)

«Отклонение от нормы, %» на предметном дашборде:
`marts.mart_price_latest.dev_from_norm_pct` ← `marts.mart_price_monthly` (сезонная норма по `core.fct_retail_price_monthly`) ← `core.fct_retail_price_monthly` (единые ключи через `core.map_product_code`, `core.map_region_code`; колонки `source_region_code`, `source_product_code`) ← `staging.stg_emiss__retail_prices` (типизация) ← `raw.emiss_retail_prices` (колонка `_content_hash`) ← файл `data/raw/emiss_retail/<hash>.xml.gz` (`meta.raw_files`) ← загрузка `meta.load_log` ← ЕМИСС, показатель 31448.
